GUIDE 03 / COST

홈페이지는 매달
돈을 내야 하나요?

반드시 그렇지는 않습니다. 웹빌더를 사용하는 경우 플랫폼 월 이용료가 발생할 수 있지만, 정적 웹사이트를 직접 개발해 배포하는 방식은 웹빌더 구독료 없이 운영할 수 있습니다. 다만 도메인과 외부 유료 서비스 비용은 별도일 수 있습니다.

홈페이지 운영비는 이렇게 나뉩니다

BUILDER웹빌더 이용료

아임웹·Wix·Squarespace처럼 플랫폼을 사용하는 경우 요금제에 따라 정기 이용료가 발생할 수 있습니다.

DOMAIN도메인

브랜드 주소를 유지하기 위한 도메인 등록·갱신 비용입니다.

FUNCTION외부 기능

예약, 결제, 폼, 뉴스레터, CMS 같은 기능은 사용하는 서비스에 따라 비용이 있을 수 있습니다.

MAINTENANCE유지보수

콘텐츠 수정이나 기능 추가를 외주로 맡기면 별도 작업비가 생길 수 있습니다.

정적 웹사이트는 무엇이 다른가요?

정적 웹사이트는 완성된 HTML, CSS, JavaScript 파일을 배포해 운영하는 방식입니다. 콘텐츠를 자주 직접 수정할 필요가 없는 랜딩페이지나 브랜드 소개 사이트라면 구조가 단순하고 웹빌더 요금제에 묶이지 않는 장점이 있습니다.

반대로 메뉴·상품·게시글을 자주 직접 수정해야 한다면 CMS나 웹빌더가 더 편할 수 있습니다. 어떤 방식이 좋은지는 운영 방식에 따라 달라집니다.

PAGE ATELIER의 운영 방식

PAGE ATELIER는 랜딩페이지를 웹빌더 월 구독료 없이 운영할 수 있는 방식으로 제작합니다. 브랜드 정보와 문의·예약 동선을 명확하게 정리하는 데 초점을 둡니다.

관리자 페이지, 회원가입, 예약·결제, 데이터 저장처럼 동적인 기능이 필요한 경우에는 프로젝트 범위에 맞춰 별도 방식과 비용을 안내합니다.
