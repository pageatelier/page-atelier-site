# PAGE ATELIER — 4 Page Website

## 구성
- `index.html` — About / 메인
- `works.html` — 포트폴리오
- `services.html` — 서비스와 프로세스
- `contact.html` — 문의 폼
- `styles.css` — 전체 반응형 디자인
- `script.js` — 모바일 메뉴, 스크롤 등장, 서비스 아코디언, 문의 메일 연결

## 사용 전 변경할 항목
`contact.html`에서 아래 임시 정보를 실제 계정으로 바꿔 주세요.
- `hello@pageatelier.kr`
- `@pageatelier`
- 문의 폼의 `data-contact-email`

## 배포
모든 파일을 같은 폴더에 둔 뒤 GitHub Pages 또는 Cloudflare Pages에 그대로 업로드하면 됩니다.
